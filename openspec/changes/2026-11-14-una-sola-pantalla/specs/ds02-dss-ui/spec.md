## No delta

The deployed capabilities say nothing about a two-mode view or an operator surface. The
«Vista» control and its gated blocks were never specified, so removing them is not a
capability change and requires no MODIFIED/ADDED/REMOVED requirement. This document records
that decision so the archive explains why a visible control disappeared without a spec
delta.

The requirement «Live metrics from cached predictions» keeps its promise: every metric on
the single screen is still computed from the cache.
